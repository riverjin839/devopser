## 내 목소리 + AI 편곡 곡 작업 - Suno 로 편곡하고 음원 발매까지

> **목표** : 탑라인·가창은 내가, 편곡·장르·악기 스템은 Suno 가 맡는 구조로 곡을 만들고 권리 신고·유통까지 끝내는 흐름 정리

- 출처 : Suno 공식 블로그·릴리즈 노트·헬프센터, 한국음악저작권협회 개정 규정 보도, Spotify 뉴스룸, DistroKid 정책 정리 글
- 기준 버전 : Suno v6 (2026-09 출시) · Suno Studio 2.0 (2026-08) · 음저협 AI 신고 기준 (2026-08-03 시행), 2026-11 기준

---

## 1. 개요

사람이 곡의 뼈대(멜로디·가사·목소리)를 만들고, AI 는 그 위에 옷(편곡·악기)을 입히는 구조임.
반대 방향(AI 가 곡 전체를 만들고 사람이 고르기만 함)과는 권리·유통 처리가 완전히 다르다.

<!-- diagram: suno-01-overview.html -->

**탑라인과 가창을 사람이 쥐고 있어야 작사·작곡 저작권과 "AI 보컬 아님" 표기가 둘 다 살아남음**

## 2. 개념 정리

### 2-1. 역할 분담

| 영역 | 담당 | 결과물 | 권리 관점 |
|---|---|---|---|
| 작사 | 사람 | 가사 | 저작권 신고 대상 |
| 작곡(멜로디) | 사람 | 탑라인 | 저작권 신고 대상 |
| 가창 | 사람 | 본 보컬 트랙 | 실연자 권리, AI 보컬 아님 |
| 편곡·장르 | AI (Suno) | 반주 전체 | 음저협에 "편곡 - AI 전체" 로 신고 |
| 악기 연주 | AI (Suno) | 스템 | 유통 시 AI 사용 공개 대상 |

<!-- diagram: suno-02-roles.html -->

### 2-2. 탑라인(Topline)

- 반주 위에 얹히는 보컬 멜로디와 가사를 합친 것
- 이 구조에서는 탑라인이 먼저 있고, 반주가 나중에 따라옴 → 일반 트랙 메이킹과 순서가 반대
- 가이드 녹음 단계에서 템포·키가 사실상 확정됨. 단, Suno 가 해석한 박자감이 내 의도와 다를 수 있어서 BPM 은 프롬프트에 명시하는 게 안전함

### 2-3. Suno 쪽 핵심 기능 (2026-11 기준)

| 기능 | 하는 일 | 요금제 | 상태 |
|---|---|---|---|
| v6 / v6-wild / v6-mini | 생성 모델. v6 = 정확·안정, v6-wild = 실험적, v6-mini = 빠른 무료 모델 | v6·wild = Pro·Premier, mini = 전체 | GA (2026-09-09) |
| Add Instrumental | 업로드한 보컬(아카펠라·스케치)을 기준으로 반주 생성 | Pro·Premier | 제공 중 |
| Add Vocals | 반대 방향. 반주 위에 가사로 보컬 생성 | Pro·Premier | 베타 |
| Voices | 내 목소리를 등록해서 AI 가 내 음색으로 노래 | 유료 | v5.5 (2026-03) 부터 |
| 스템 분리 | Auto Split(12종), Split from Mix, Advanced Split(약 100개 악기) | 유료 | 2026-06 개선 |

- 스템 분리는 믹스를 칼로 잘라내는 방식이 아니라, 원곡을 듣고 각 악기를 새로 생성하는 방식이라고 Suno 가 설명함 → 블리드(bleed)는 적지만 원본과 미세하게 다를 수 있음
- v6 출시와 함께 이전 모델은 은퇴 수순임. v6 는 Warner·BMG 등과 라이선스한 데이터로 학습했다고 발표됨

> 주의 : Voices 는 "내 목소리를 학습한 AI 가 부르는 것" 임. 이걸 쓰면 가창도 AI 영역이 되고, 유통 시 AI 보컬로 공개해야 함. 이 구조에서는 쓰지 않음

### 2-4. 다운로드와 상업적 사용 (2026-09-03 약관부터)

| 요금제 | 다운로드 | 상업적 사용 |
|---|---|---|
| Free | 평생 7곡 (체험용) | 불가 |
| Pro | 월 20곡, 이월 없음 | 가능 |
| Premier | 월 60곡, Studio 내보내기는 무제한 | 가능 |

- 상업적 사용권은 "구독 중에 만든 곡" 에만 붙음. 무료로 만든 곡을 나중에 구독해도 소급 안 됨
- 구독을 끊어도 구독 중에 만든 곡의 상업적 사용권은 유지됨
- Suno 는 결과물에 저작권이 생긴다고 보증하지 않음 → 저작권 인정 여부는 각 나라 기관이 판단

> 주의 : 스템을 여러 번 뽑고 버전을 비교하는 작업이면 Pro 의 월 20곡 한도가 금방 참. 스템 위주 작업이면 Premier + Studio 내보내기가 사실상 기본값임

## 3. 작업 흐름

### 3-1. Suno 안에서

<!-- diagram: suno-03-suno-flow.html -->

1. 보컬 업로드 : 메트로놈 맞춰 부른 아카펠라 또는 피아노+보컬 스케치. 업로드는 최대 8분
2. 스타일 지정 : 장르, BPM, 키, 원하는 악기, 분위기를 짧게. 아티스트 이름은 넣지 않음 (정책상 막힘)
3. Add Instrumental 로 생성 : 한 번에 2곡씩 나옴
4. 후보 비교 : 마음에 안 들면 프롬프트를 고쳐서 다시. 아이디어가 막히면 v6-wild 로 몇 번 돌려 보고, 좋은 방향을 v6 로 다듬음
5. Studio 2.0 : 섹션 정리, 필요 없는 악기 삭제, 스템 분리
6. 스템 내보내기 : 32bit/48kHz WAV 로 DAW 에 가져감

### 3-2. DAW 에서 (Logic Pro)

- 스템을 프로젝트 템포에 맞춰 정렬 → 가이드 보컬과 박이 맞는지 먼저 확인
- 본 보컬을 반주 위에서 다시 녹음. 가이드는 반주가 없는 상태라 다이내믹·숨 위치가 반주와 안 맞는 경우가 많음
- 마음에 안 드는 악기 스템은 직접 연주로 교체 (특히 건반)
- 믹스 → 마스터링. 스트리밍 기준 라우드니스는 보통 -14 LUFS 근처로 맞춤 (Spotify 정규화 기준)

### 3-3. 대안 비교

| 방식 | 장점 | 단점 | 언제 쓰나 |
|---|---|---|---|
| 내 보컬 + Add Instrumental (이 글) | 탑라인·가창이 온전히 사람 몫, 권리 정리가 깔끔함 | 반주를 내 보컬에 맞추는 데 생성 횟수가 꽤 듦 | 멜로디·가사는 있는데 편곡 역량·시간이 부족할 때 |
| AI 반주 먼저 + 내 보컬 녹음 | 반주 품질을 먼저 고를 수 있음 | 멜로디가 반주에 끌려감, 탑라인 독창성 약해짐 | 곡 분위기부터 찾고 싶을 때 |
| Voices (내 음색 AI 가창) | 노래 실력·녹음 환경 무관 | 가창이 AI 영역, AI 보컬 공개 대상 | 데모·스케치용 |
| 전부 사람 (세션 섭외) | 권리 가장 단순 | 비용·시간 큼 | 정식 앨범 타이틀곡 |

## 4. 권리 신고와 유통

<!-- diagram: suno-04-rights.html -->

### 4-1. 한국음악저작권협회(KOMCA) 신고

- 2025-03 부터는 "AI 안 썼다" 보증한 곡만 받았음 → 2026-07-28 이사회 의결, 2026-08-03 부터 AI 활용 곡도 등록 가능해짐
- 조건 : 사람이 작사·작곡·편곡에 실질적으로 참여해야 함. 프롬프트만 넣고 AI 가 전부 만든 곡은 제외
- 신고서에서 "AI 활용" 선택 + 곡당 1장 「AI 활용 확인서」 첨부
- 확인서에는 AI 를 쓴 파트(작사·작곡·편곡)와 "일부 / 전체", 사용한 도구명 등을 적고 서약·서명함
- 특정 파트를 "전체" 로 고르면 그 파트는 징수·분배 대상에서 빠질 수 있음. 세 파트 모두 "전체" 면 등록 자체가 제한될 수 있음

이 구조에 대입하면

| 파트 | 표시 | 결과 |
|---|---|---|
| 작사 | 표시 안 함 (AI 미사용) | 분배 대상 |
| 작곡 | 표시 안 함 (AI 미사용) | 분배 대상 |
| 편곡 | AI 전체 (건반 등을 직접 바꿨으면 일부) | 편곡 몫은 빠질 수 있음 |

> 주의 : AI 보조로만 썼어도 신고 대상임. 숨기고 등록하면 나중에 분쟁 시 불리함. 현재 감액 비율 같은 산식은 공개된 게 없음

### 4-2. 유통·DSP 의 AI 표기

| 대상 | 현재 정책 | 이 구조에서 할 일 |
|---|---|---|
| Spotify | DDEX 표준으로 AI 사용을 크레딧에 표기. 보컬·악기·후반작업 단위로 구분 가능. 스팸 필터, 무단 음성 복제 금지 | 악기(instrumentation) = AI, 보컬 = 사람 으로 표기 |
| YouTube Music | 2026-10-14 AI 음악 라벨 도입 발표. 생성형 AI 가 결정적 역할을 했는지가 기준 | 유통사 신고 항목에 맞춰 정직하게 기재 |
| Apple Music | 2026-03 공급 피드에 AI 투명성 태그 도입 | 동일 |
| DistroKid | 4가지 규칙 : 권리 100% 보유, 남의 목소리 복제 금지, 대량 스팸 금지, 권리 침해 금지 | Suno 유료 구독 중 생성·다운로드한 기록 보관 |
| 국내 플랫폼 | 2026-09 보도 기준 발매 등록 양식에 AI 사용 항목 없음 | 유통사 정책을 개별 확인 |

- TuneCore 는 100% AI 생성 콘텐츠를 거부한다고 정리 글들에 나옴. 이 구조는 100% AI 가 아니라서 해당 안 되지만, 유통사 바꿀 때 약관은 다시 확인 필요

## 5. 사용법 예시

### 5-1. 스타일 프롬프트 (개념 예시)

```text
Style: contemporary worship ballad, 72 BPM, key of D major,
warm grand piano, soft pad, light acoustic guitar, brushed drums,
gradual build into last chorus, no backing vocals
```

- 아티스트 이름 대신 장르·템포·키·악기·구성을 씀
- "no backing vocals" 처럼 빼고 싶은 것도 적어 둠. 내 보컬 외 다른 목소리가 섞이면 AI 보컬 공개 대상이 됨

### 5-2. 작업 기록 남기기

음저협 확인서와 유통사 분쟁 대응용. 인간 기여를 보여 줄 근거를 곡마다 남김.

```yaml
# song-log.yaml  (곡마다 1개)
title: 곡 제목
topline:
  melody_memo: 2026-11-02_voice-memo.m4a   # 처음 흥얼거린 날짜가 남는 파일
  lyrics_draft: lyrics_v1.txt
  guide_vocal: guide_72bpm_D.wav
suno:
  plan: Premier                # 생성 당시 구독 상태
  model: v6
  feature: Add Instrumental
  generations: 14              # 생성 횟수
  chosen: suno_take_09
  downloaded_at: 2026-11-10
human_edits:
  - 피아노 스템 삭제 후 직접 연주로 교체
  - 2절 드럼 구간 삭제, 브릿지 재배치
  - 본 보컬 재녹음, 믹스·마스터링
komca_ai_parts: { 편곡: 일부 }    # 직접 교체가 없으면 "전체"
```

## 6. 실무에서 확인 - 내 환경 관점

- Logic Pro + Neumann MT48 조합이면 스템 가져오기·보컬 녹음·믹스까지 추가 장비 없이 됨. Suno Studio 는 VST·AU 플러그인을 못 씀 → 이펙트·믹스는 Logic 에서 마무리하는 게 맞음
- 재즈 피아노가 되니까 건반 스템은 직접 연주로 바꾸는 게 이득임. 소리도 좋아지고, 음저협에 편곡을 "전체" 가 아니라 "일부" 로 적을 근거가 생김
- MIDI 키보드(M-VAVE SMK-37)는 37건반이라 피아노 본 연주엔 짧음. 패드·스트링 보강용으로 쓰고, 피아노 파트는 88건반으로 녹음하는 게 편함
- 3평 방 녹음이면 보컬 반사음이 생각보다 많이 남음. 반주가 AI 라 깨끗할수록 보컬 룸톤이 더 도드라짐 → 리플렉션 필터나 흡음부터 챙김
- 다운로드 한도가 월 단위라서 "생성은 넉넉히, 다운로드는 최종 후보만" 이 원칙임. 프로젝트 관리처럼 후보를 Suno 안에서 비교하고, 확정본만 내보냄
- 교회 예배용으로 쓰는 곡과 발매용 곡은 분리해서 관리하는 게 편함. 발매용은 위 작업 기록을 처음부터 남겨야 나중에 다시 만들 일이 없음

> 주의 : 약관·다운로드 한도·플랫폼 AI 정책은 2025-11 이후 1년 사이에 여러 번 바뀜. 발매 직전에 Suno 약관, 유통사 AI 정책, 음저협 서식을 한 번 더 확인할 것

## 7. 용어 정리

- **탑라인(Topline)** : 반주 위에 얹는 보컬 멜로디와 가사
- **스템(Stem)** : 드럼·베이스·건반처럼 악기 그룹별로 나눈 오디오 트랙
- **Add Instrumental** : 업로드한 보컬을 기준으로 Suno 가 반주를 생성하는 기능
- **Suno Studio** : Suno 의 브라우저 기반 생성형 DAW. 2.0 부터 MIDI·이펙트·채팅 편집 지원
- **v6-wild** : 결과가 덜 예측 가능하게 나오는 실험용 v6 모델
- **Voices** : 내 목소리를 등록해 AI 가 내 음색으로 부르게 하는 기능
- **DDEX** : 음원 메타데이터 국제 표준. AI 사용 여부를 크레딧에 적는 항목이 생김
- **DSP(Digital Service Provider)** : Spotify·Apple Music·멜론 같은 스트리밍 서비스
- **AI 활용 확인서** : 음저협에 AI 활용 곡을 신고할 때 곡당 1장 붙이는 서식
- **LUFS** : 체감 음량 단위. 스트리밍 서비스가 음량 정규화에 사용
- **ISRC** : 녹음물(음원)마다 붙는 국제 식별 코드. 유통사가 발급

| 항목 | 핵심 |
|---|---|
| 구조 | 탑라인·가창 = 사람, 편곡·악기 = Suno, 선택·믹스 = 사람 |
