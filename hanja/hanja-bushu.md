## 한자 부수 - 모양 · 획순 · 병음 정리

> **목표** : 자주 쓰는 한자 부수 57개를 모양 · 획순 · 의미 · 병음 · 예시 단어로 한 번에 정리
- 출처 : 강희자전 214부수 중 빈출 부수 선별, 병음은 간체자 기준
- 기준 : 2026-11

---

## 1. 개요

한자는 대부분 의미 부분(부수)과 소리 부분이 합쳐진 구조임
- 부수 = 의미 범주 힌트 → 모르는 한자도 뜻을 대략 추측 가능
- 소리 부분 = 발음 힌트 → 清 qīng, 请 qǐng, 情 qíng, 晴 qíng 처럼 青 을 공유하면 발음이 비슷함
- 사전은 부수 + 나머지 획수로 찾음

**부수 하나만 알아도 뜻의 방향과 사전 찾기가 동시에 해결됨**

## 2. 개념 정리

### 2-1. 부수 위치 이름 - 한국 vs 중국

한국은 위치에 따라 변 · 방 · 머리 · 발 · 받침 · 엄 · 몸 으로 부름
중국은 같은 위치를 旁(páng) · 头(tóu) · 底(dǐ) · 框(kuàng) 으로 부름

<!-- diagram: hanja-position.html -->

| 위치 | 한국 | 중국 | 예 |
|---|---|---|---|
| 왼쪽 | 변 | 旁 páng | 亻 单人旁 dānrénpáng, 氵 三点水 sāndiǎnshuǐ |
| 오른쪽 | 방 | 旁 páng | 刂 立刀旁 lìdāopáng |
| 위 | 머리 | 头 tóu | 艹 草字头 cǎozìtóu |
| 아래 | 발 | 底 dǐ | 灬 四点底 sìdiǎndǐ |
| 왼쪽 + 아래 | 받침 | 底 dǐ | 辶 走之底 zǒuzhīdǐ |
| 왼쪽 + 위 | 엄 | 头 tóu | 广 广字头 guǎngzìtóu |
| 바깥 둘러쌈 | 몸 | 框 kuàng | 门 门字框 ménzìkuàng |

모양을 따라 쓰는 법이 곧 획순임. 아래 8가지만 알아도 대부분 해결됨

## 5. 한국어와 중국어 비교

- 간체자에서는 모양이 바뀜 : 言→讠, 食→饣, 金→钅, 糸→纟, 門→门, 車→车, 貝→贝, 魚→鱼, 鳥→鸟
- 부수 이름 방식이 다름 : 한국 = ~변 · ~방 · ~머리, 중국 = ~旁 · ~头 · ~底 · ~框
- 한국 음과 병음이 꽤 다름 : 学 학 ↔ xué, 药 약 ↔ yào
- 성조는 따로 외워야 함 : ā(1성 높고 평평) á(2성 올라감) ǎ(3성 내려갔다 올라감) à(4성 확 떨어짐)

## 6. 공부할 때 확인

- 214자를 순서대로 외우기보다 빈출 부수 → 위 표 순서가 효율적임
- 모양이 비슷한 쌍을 따로 묶어 외움 : 日 / 曰, 己 / 已 / 巳, 土 / 士, 末 / 未
- 새 한자를 만나면 부수 → 뜻 추측 → 소리 부분 → 발음 추측 순서로 읽음
- 병음 성조는 한국 음으로 유추되지 않으므로 단어 단위로 소리 내어 확인함
- 획순은 손으로 3번 이상 써야 몸에 붙음

## 7. 용어 정리

- **부수(部首, bùshǒu)** : 한자를 분류하는 기준이 되는 구성 요소, 보통 의미 힌트
- **병음(拼音, pīnyīn)** : 중국어 발음을 로마자와 성조 부호로 적는 표기법
- **성조(声调, shēngdiào)** : 음의 높낮이 변화, 표준 중국어는 4성 + 경성
- **간체자(简体字)** : 획을 줄여 단순화한 현대 중국 문자
- **번체자(繁體字)** : 전통 한자, 한국 · 대만 · 홍콩에서 주로 사용
- **획순(笔顺, bǐshùn)** : 한자를 쓰는 순서
- **변(旁) · 방** : 부수가 왼쪽 · 오른쪽에 오는 위치
- **머리(头) · 발(底)** : 부수가 위 · 아래에 오는 위치
- **받침 · 엄** : 왼쪽 + 아래로 감싸는 辶 류, 왼쪽 + 위로 덮는 广 류
- **몸(框)** : 안쪽을 바깥에서 둘러싸는 부수, 門 · 口 류
- **형성자(形声字)** : 의미 부분 + 소리 부분으로 이뤄진 한자, 전체의 대다수
- **육달월(⺼)** : 月 모양이지만 실제로는 肉(몸)을 뜻하는 부수

## 8. 한 장 요약

| 항목 | 핵심 |
|---|---|
| 부수의 역할 | 의미 힌트 + 사전 색인 |
| 소리 부분 | 같은 글자를 공유하면 발음이 비슷함 (青 → 清 请 情 晴) |
| 획순 | 위→아래, 왼→오른, 가로→세로, 바깥→안, 꿰뚫는 획과 점은 마지막 |
| 변형 부수 | 氵 = 水, 扌 = 手, 忄 = 心, 亻 = 人, 讠 = 言 |
| 위치 이름 | 한국 변 · 방 · 머리 · 발 = 중국 旁 · 头 · 底 |
| 병음 | 간체자 기준, 성조 4개는 따로 암기 |

**빈출 부수 57개 + 변형 11개만 익히면 대부분의 한자는 뜻의 방향이 보인다**
