## gliffy

Confluence **Gliffy** 에서 draw.io XML 가져오기용 세트. 그림 내용은 상위 폴더와 같음.

| 차이 | 상위 폴더 (draw.io · Confluence draw.io) | gliffy/ |
|---|---|---|
| 장비 | Cisco 아이콘 + 아래 이름 | 이름이 안에 든 상자 (스위치 파랑 · AIStor 그린 · 그 외 회색 · FA Core / client 흰색) |
| 연결선 라벨 | 선에 붙은 라벨 | 선 중간의 별도 글자 칸 |

- Gliffy 에서 그대로 표시가 확인된 요소(N-0 : 상자 · 글자 칸 · 구역 · 라벨 없는 선)만 사용
- 글꼴 Helvetica 1개, 일반 텍스트 라벨, `<...>` 대신 `[...]` 표기
